# RFCs

Changes to Pullboard's standard doctrine, and other changes that affect every repo using Pullboard, are proposed as RFCs.

An RFC is one file here, numbered next: what changes, why, what it costs, and who it affects. Propose it in a pull request. Discussion stays open at least 14 days, then the maintainers accept or decline it and record why in the file.
